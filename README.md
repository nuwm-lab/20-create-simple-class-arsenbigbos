Створити об’єкт класу „арифметична прогресія”. Клас характеризується першим членом a 0 , різницею d та кількістю членів n . Визначити за допомогою методу класу суму прогресії.

Ось приклад створення класу в C#, який представляє арифметичну прогресію. Клас включає властивості для першого члена 𝑎 0 a 0 ​ , різниці 𝑑 d, кількості членів 𝑛 n і метод для обчислення суми прогресії.
Пояснення:
Клас ArithmeticProgression:
Містить приватні поля a0, d, і n.
Має властивості для доступу до полів.
Метод CalculateSum() обчислює суму прогресії за формулою
Випадковий 𝑎 0 a 0 ​ : У конструкторі створюється об'єкт класу Random. Метод NextDouble() використовується для генерації числа у діапазоні [0.1, 5].
Результат округляється до 2 знаків після коми за допомогою Math.Round().


Конструктор:
Ініціалізує поля при створенні об'єкта.
Метод DisplayInfo():
Виводить інформацію про прогресію та її суму.
Головний метод Main:
Демонструє створення об'єкта, зміну властивостей і виклик методів.
Цей код легко розширюється для додаткових операцій з прогресією.
